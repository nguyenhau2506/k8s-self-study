## 🧠 Câu thần chú cần nhớ

> - **Node chết** → **Node Controller** đánh dấu Pod tử trận → **ReplicaSet Controller** đẻ Pod mới → **Scheduler** chọn node → **kubelet+containerd** chạy. Pod cũ **không** sống lại.
> - **Scheduler quyết Node, ghi etcd** · **Kubelet đọc qua API Server, gọi containerd**. Tất cả đi qua **API Server** (hub-and-spoke).
> - Pod chậm tạo → **đừng đổ lỗi Dockershim** (đã chết từ v1.24). Debug: **image pull → scheduler → CNI → etcd → admission webhook**.
